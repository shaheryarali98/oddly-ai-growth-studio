# Oddly — AI agency website concept

An original cinematic localhost concept for an AI-led growth studio. It combines nine locally hosted video treatments, scroll-led storytelling, service and case-study sections, and an interactive browser-based client reporting portal demo.

## Run locally

```powershell
npm start
```

Then open [http://localhost:4173](http://localhost:4173).

The demo has no database or real authentication. Client login and reporting data are intentionally simulated for presentation and stakeholder review. Videos are streamed locally with byte-range support for smoother playback.
